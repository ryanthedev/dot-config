## Tarball fallback

**Both archives were built and verified on 2026-09-11.** Ryan chose tarball-only (no git remote for the brain yet), so `migration-secrets-*.tgz` is the **sole off-machine copy of the primary brain**.

> **macOS `tar` gotcha:** `--exclude` must come **before** the file list. bsdtar treats trailing `--exclude=...` as filenames, silently ignores the exclusions, and exits non-zero. The commands below have the working order.

### 1. `~/migration-secrets-2026-09-11.tgz` (79MB) — secret-bearing, never to Drive

```sh
cd ~ && tar czf ~/migration-secrets-$(date +%F).tgz \
  --exclude='*.db' --exclude='*.db-wal' --exclude='*.db-shm' \
  --exclude='.ssh/agent' --exclude='.DS_Store' \
  .ssh \
  .grug-brain/brains.json .grug-brain/memories \
  .claude/CLAUDE.md .claude/settings.json .claude/settings.local.json \
  .claude/skills .claude/plans .claude/projects \
  grug-brain.mcp/memories \
  Library/LaunchAgents/com.grug-brain.server.plist
```

Verified contents: **122 brain md files** (matches disk), **728 git objects** (full brain history rides along), `recall.md` present, 17 `.ssh` entries, `voice-profile.md` present, **0 leaked `.db` files**, `gzip -t` OK. `.ssh/agent` is excluded because it holds a socket tar can't archive.

### 2. `~/migration-config-2026-09-11.tgz` (18MB) — also secret-bearing (`zsh/.env`, `aerospace/.env`)

```sh
cd ~ && tar czf ~/migration-config-$(date +%F).tgz \
  --exclude='.config/gcloud' --exclude='.config/gh' --exclude='.config/acli' \
  --exclude='.config/github-copilot' --exclude='.config/configstore' \
  --exclude='.config/.claude' --exclude='.config/tmux/plugins' \
  --exclude='.config/services/logs' --exclude='.config/.git' \
  --exclude='*.log' --exclude='*.sock' --exclude='.DS_Store' \
  .config
```

Verified: `app-launchers/` (43 entries), `stele/theme.toml`, `zsh/.env`, `aerospace/aerospace.toml`, `scripts/`, `raycast/` (52), `bin/dabootstrap`, `Brewfile` all present; **0** files from the excluded auth caches; `gzip -t` OK.

**Both archives are sitting on the machine you're about to wipe.** Move them to a USB or external drive before doing anything else.
